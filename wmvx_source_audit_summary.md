# Краткое резюме WMVx для аудита T11

- **Пригодность:** исходный код подтверждает, что WMVx способен помочь подобрать визуальные прототипы; в нём есть WotLK MPQ/DBC профиль, поиск экипировки по Item ID и preview на персонаже. Практическая совместимость с локальным build 12340 ещё не проверена.
- **Что способен проверить:** отдельные M2 и связанные текстуры; Item ID → выбор связанного DisplayID; показ предмета в слотах персонажа; сборка полного preview комплекта; часть изменений geoset и race/gender.
- **Ограничения визуального вывода:** прозрачность и текстурная анимация WotLK перечислены в README как проблемные. WMVx не подтверждает принадлежность T4/T5 набору через ItemSet.dbc в проверенном WotLK-профиле.
- **Netherblade Facemask:** код поддерживает поиск предмета по `29044` и затем выбор DisplayID; механизм пути `Item.dbc → ItemDisplayInfo` подтверждён. Фактическая строка `29044 → 45810` и её render на нашем клиенте **UNVERIFIED**, WMVx не запускался.
- **Полный комплект на персонаже:** отдельный инструмент для этого в принципе не обязателен — код WMVx содержит экипировочный preview и character equipment slots. Но итоговую корректность geosets, текстур и прозрачности требуется сравнить с игрой.
- **Версия:** официальный репозиторий [Frostshake/WMVx](https://github.com/Frostshake/WMVx), ветка `main`, последняя видимая ревизия `90a4d9e7d4fffb4af483f2fe5d11489ae1d5d42c`. Release `v0.5.2` старше на два коммита и может не включать исправление поиска текстур по расе/полу.
- **Следующий шаг:** после отдельного согласования выбрать и зафиксировать артефакт/commit, затем выполнить один изолированный тест на Netherblade Facemask в каталоге аудита с проверкой отсутствия записей в клиент. Не скачивать, собирать или запускать до такого согласования.
