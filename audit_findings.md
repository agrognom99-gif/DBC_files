## Ограничения и следующие действия

- Для выбора прототипов нужно получить названия/специализации всех 19 целевых комплектов. Без этой карты нельзя корректно связать кандидата с конкретным целевым комплектом.
- Все кандидаты основаны на T4/T5 membership; так как для каждого класса/специализации в этих данных есть наборы по 5 предметов, поиск WotLK альтернатив для заполнения пробелов не запускался. Это предварительно по записям, не визуальная пригодность.
- Просмотр модели/текстур обязателен до статуса «визуально подтверждено». В текущем окружении отдельного ModelViewer не найдено; `.m2`/`.blp` в MPQ не читаются.
- Поля класса/подкласса в `Item.dbc` подтверждены как целые значения; человекочитаемые наименования из ItemClass/ItemSubClass не назначались, поскольку полные layouts не подтверждены серверными источниками.
- Не создавались изменения сервера/клиента, SQL, патчи или игровые данные.
